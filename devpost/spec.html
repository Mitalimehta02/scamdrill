Free tier: 30 requests/min, 1,000 requests/day and 8,000 tokens/min per model. A drill makes about 20 calls, so there's room for about 45 drills a day.

Components, with the PRD behaviours they implement

The safety guard, in order

  1. Exact fake OTP → loss: shared the OTP
  2. Remove phone numbers first (+91 98765 43210 has 12 digits, like an Aadhaar number) → never blocked
  3. Aadhaar · card · PAN · a code word next to digits → loss: tried to share
  4. A 4–6 digit number (not an amount or a year): at stage 5 or later and mostly just the number, or next to a code word → loss
  5. Anything else → sent (with placeholders)

How to run it

npm install
copy .env.example .env        # add AI_API_KEY; turn on Groq Zero Data Retention
npm run test:refusal          # will it play the role?
npm run dev                   # → http://localhost:5173   (demo: /?demo=1)
npm test                      # guard / reducer / placeholder tests

Stretch goal: npm run build:demo gives a static site that only runs demo mode, for GitHub Pages or Vercel.

Decisions and open issues

Your uncertainty: prompts that won't be refused
Frame it as a consented training simulation with a fictional character. Use short lines driven by beats. Ban real numbers and links. Keep the classifier's wording clinical. Evidence: npm run test:refusal gives 10 in-character lines and valid classifier JSON. If not, change the framing, and then fall back to Gemini.
