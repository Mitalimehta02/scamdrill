ScamDrill

A fire drill for scams, set up by the family.

SCOPE APPROVED

The kernel

A family-personalised, open-ended scam rehearsal that trains the exit reflex, not knowledge. The scammer uses the family's own details, every tactic is named live, losing is detected by code rather than guessed by the AI, and the report card goes back to the child.

"Fire drills work the same way — everyone knows it's a drill, but the body learns the exit route."

Grounded in prebunking research, e.g. the Cambridge Bad News game.

Who it's for

The child

An adult in India whose elderly parent could get a "digital arrest" call. Today they forward WhatsApp warnings, which don't build a reflex. They set up the drill and read the report card.

The parent

An elderly person who trusts officials and picks up their calls. Today they get no practice before the real call. They do the drill.

The core loop: one device, passed from hand to hand

How the drill stays reliable

The app sets the pace through a fixed script of stages. The AI only writes the dialogue for the current stage. The meter uses only the tactic tags. Step through a run below. The point values are the examples you proposed; the final numbers are set in the spec.

Pressure 0 / 100

If the classifier call fails or returns junk, the app uses the tactic planned for the current stage, so the drill never breaks.

What "working" looks like

A stranger can go from setup to the drill to the report card, win or lose, with no errors, in under 3 minutes.

The "oh, that's cool" moment: the fake OTP SMS slides in while "Inspector Sharma" demands it, the chips light up and the meter spikes. You see why real people give in, and the exit buttons are right there.

Boundary

Now PROOF OF CONCEPT
  • One scenario (digital arrest), English only, text chat, one device
  • Setup (with "Use demo details"), handoff, drill and report card screens
  • Live tactic chips with one-line explanations, pressure meter
  • Deterministic endings: win, OTP loss, payment loss, partial
  • Safety: permanent training banner, fake data only, nothing real asked for or stored, consented-simulation prompt, API key in a gitignored .env
Later STRETCH
  • Hindi and Hinglish (first stretch goal: language is a prompt variable)
  • Grandparent-scam scenario, for US judges
  • Voice mode
  • Send the drill to the parent's own phone by link
Cut WITH REASONS
  • Accounts and login: not needed to prove the drill works; friction in the demo
  • Databases: session state is enough, and "store nothing real"
  • Real calls and SMS: unsafe and legally risky; the in-app fake SMS proves the point
  • Deployment complexity: judges watch the video and don't run the code
  • AI deciding when the parent has lost: replaced by code-based OTP and Pay detection

Why it matters

Indians lost ₹1,935 crore to digital arrest scams in 2024 (government data, reported by Inc42). Elderly people are heavily targeted, and WhatsApp warnings don't build the reflex to hang up. Practice does.
